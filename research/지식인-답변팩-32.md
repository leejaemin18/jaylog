## 핵심 포인트 (정확도)
- 토요일 신청 → 세관 심사는 평일 처리. 주말·공휴일엔 통관 업무 거의 멈춤 → 세액 안내는 월요일 이후 순차. 통상 신청 후 1~3 영업일.
- 순서: 세관 심사 → 세액 확정·납부 고지 → 납부 → 수입신고 수리(통관 완료) → 보세창고 반출 → 배송/직접 수령.
- 관세 바로 납부 시 통관 수리 → '반출'되면 직접 수령 가능(보통 납부 당일~다음 날).
- 현재 상태는 유니패스에서 운송장/개인통관고유부호로 조회, '반출' 뜨면 수령 단계.

## 붙일 답변
간이통관 신청을 토요일 오전에 하셨다면, 세관 심사는 보통 평일에 처리돼요. 주말·공휴일엔 통관 업무가 거의 멈춰서, 실제 세액 산정과 '관세 내라'는 안내는 월요일 이후부터 순차로 오는 경우가 많습니다. 물량이 몰리거나 검사 대상이 되면 하루이틀 더 걸리기도 하고요. 보통은 신청 후 1~3 영업일 안에 세액 안내가 오는 편입니다.

순서는 이래요. 세관 심사 → 세액 확정·납부 고지(문자/카톡) → 관세 납부 → 수입신고 수리(통관 완료) → 보세창고 반출 → 배송 또는 직접 수령. 관세를 바로 내시면 통관이 수리되고, 물건이 창고에서 '반출'되면 그때부터 특송사나 창고에서 직접 수령이 가능해요. 납부 당일에서 다음 날 사이에 반출되는 경우가 많습니다.
