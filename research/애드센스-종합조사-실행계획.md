# 구글 애드센스 종합 조사 + 제이로그 실행 계획 (2026-09-13)

거절 사유: **"가치가 별로 없는 콘텐츠(Low value content)"**. 방문자는 늘고 있는데 계속 거절 → **트래픽 문제가 아니라 "글 품질(밀도·독창성)" 문제**임이 3중 조사로 확정됨.

이 문서는 ①애드센스 정책 완전 조사 ②승인/거절 실제 사례 비교 ③제이로그 44개 글 전수 분석을 합친 **결론 + 글별 실행 계획**이다.

---

## ⭐ 3줄 결론
1. 애드센스 승인은 **글 개수·글자 수가 아니라 "정보 이득(information gain) + E-E-A-T(경험·전문성·권위·신뢰)"** 싸움이다. 우리 니치(해외직구·통관)·글 수(44개)·자체도메인은 **이미 승인권** — 유일한 약점은 **얇은 글**과 **이미지/출처 공백**.
2. **글을 더 쓸 게 아니라, 있는 얇은 글을 심화하고 이미지·통계표·출처를 채워 "밀도"를 올리는 게 정공법.** 실제 사례에서도 "삭제·통합·심화"로 저가치를 뚫었다.
3. **명백한 정책위반(불법조장) 글은 없음.** 주의 2건(333 언더밸류 문구 순화, 669 주류=광고제한)만 손보면 됨.

## 1) 애드센스가 보는 것 (정책 조사 요약)

**공식 자격요건**: 만 18세↑ / 사이트 소유·HTML 접근 / 완전 공개·크롤링 가능 / 고품질·독창 콘텐츠 + 좋은 UX / Publisher Policies 준수.

**"저가치" 판정의 진짜 뿌리 = 정보 잉여**: "이미 인터넷에 널린 내용과 똑같으면 존재 이유가 없다". 2026년 크롤러는 **information gain(이 글만의 새 정보)** 을 본다.

### 저가치 트리거 Top 10
| # | 트리거 | 처방 |
|---|---|---|
| 1 | 정보 이득 없음(어디에나 있는 내용) | 1차 데이터·경험·독자 분석 주입 |
| 2 | 얇은 글(짧고 표면적) | 깊이·예시·예외·케이스(글자 수만 늘리는 건 X) |

### 정책위반 유형 (제이로그 관점)
- **하드 금지(계정 위험)**: 불법·성인·저작권 침해·해킹/부정행위 조장 등. → **의약품·처방약 직구는 국내 불법 = 하드 위반**(이미 post 59 삭제 완료, 현재 없음 확인).
- **광고 제한(위반은 아니나 광고 수요↓)**: 주류·담배·도박·규제 의약품·총기. → **669 위스키·와인**이 여기 해당. 승인은 막지 않지만 그 페이지에 광고가 덜 붙을 수 있음.
- **관세 회피(언더밸류)·밀수 "실행 방법" 안내**는 "부정직 행위 조장" → 반드시 **경고·교육 프레임**으로만.

## 2) 성공 vs 실패 사례 비교 (한국 워드프레스/티스토리 2024~2026)

| 기준 | 승인(성공) | 저가치 거절(실패) |
|---|---|---|
| 글자수 | 1,500~2,000자+ | 500~1,300자 얇은 글 다수 |
| 정보 밀도 | 문제해결·비교·계산·사례 | 표면 일반론·요약형 |
| 독창성 | 직접 경험·실측·1차 데이터 | 복붙·재조합·AI 양산 |
| 이미지 | 2~3단락당 1장(글당 3~5장) | 없거나 1~2장 |
| 구조 | 글마다 다른 포맷 | 획일적 동일 뼈대 |
| 필수 페이지 | 소개·문의·개인정보 충실 | 부실/누락 |
| 저자(E-E-A-T) | 운영자·전문성 명시 | 익명·근거 없음 |
| 결과 | **10~40개 글로 승인** | 40개여도 반복 거절 |

- 승인 소요: 빠르면 2~5일, 보통 2주~1.5개월.
- 저가치 뚫은 실전법: **얇은 글은 삭제/통합/심화** → 간판 글 5개에 데이터·경험 주입 → 필수 페이지 정비 → **2~4주 후 재신청**(신청 정보는 바꾸지 말 것, 사이트 변화를 봄).
- 참고: 200개 글이 있어도 오리지널이 5~10개뿐이면 1년 걸렸다 → **개수보다 질**.

## 4) 권장 실행 계획 (우선순위)

**목표 정량 상태**: 1,500자 미만 0개 / 글당 이미지 3~5장 / 글당 통계표 1개+1차 출처 / 필수 페이지 3종 충실 / GEO 전 글 적용.

- **[1순위] 필수 페이지 3종 점검·보강** — 소개(운영자 실체·전문성), 문의(실제 이메일), 개인정보처리방침. 없으면 콘텐츠와 무관하게 거절. (빠르고 효과 큼)
- **[2순위] 양호 11개 글 이미지 채우기** — 554·567·581·597 등 본문 이미지 0장 + 썸네일 없는 글에 로컬 이미지(썸네일+본문4장). 이미 텍스트 양호 → 즉시 승인권 진입.
- **[3순위] 얇은 글 심화** — GEO 없는 초기 9편 우선 → 국가시리즈 4편 → 나머지. 각 2,600자+·통계표·본문이미지4·GEO.
- **[4순위] 중복 정리** — 252→398 통합, 98·104 흡수(선택).
- **[5순위] 문구 순화** — 333 언더밸류 회피성 문구 순화.
- 개선 후 고가치 페이지 Search Console 색인 확인 → **2~4주 후 재신청**.
