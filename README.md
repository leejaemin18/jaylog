# 제이로그 (jaylog.co.kr) 블로그 운영 저장소

해외직구·통관 정보 블로그. 구글 애드센스 승인 → 수익화가 목표.
Claude가 REST API로 글을 직접 작성·발행한다.

## 폴더 구성
| 파일 | 내용 | GitHub 업로드 |
|---|---|---|
| `wp-api-config.md` | 사이트 구성·연동 개요 (비밀키 제외) | ✅ 올라감 |
| `글계획.md` | 글 30+개 계획, 카테고리 매핑, 발행 현황 | ✅ 올라감 |
| `작성현황.md` | 작성·발행 기록 | ✅ 올라감 |
| `agents/jaylog-writer.md` | 글쓰기 에이전트 백업본 | ✅ 올라감 |
| `secrets.local.md` | 🔒 비밀키 (OpenAI·워드프레스) | ❌ 안 올라감 (.gitignore) |
| `secrets.local.example.md` | 비밀키 템플릿 | ✅ 올라감 |

## 새 PC에서 시작하는 법
1. 이 저장소를 클론(내려받기)
2. `secrets.local.example.md`를 복사 → `secrets.local.md`로 이름 변경 → 실제 키 채우기
3. `agents/jaylog-writer.md`를 그 PC의 Claude 에이전트 폴더(`.claude/agents/`)에 복사
4. 끝. Claude에게 "제이로그 이어서" 하면 됨.

## 운영 원칙
- **하루 1개씩만 발행** (애드센스 자연스럽게)
- **단일 카테고리**(해외직구·통관 가이드)로 주제 일관성 유지
- **50대 타깃** 주제·문체 (애드센스 CPC 높음)
- 썸네일: OpenAI gpt-image-2로 고급 프리미엄 스타일 생성
- 각 글에 키워드(태그)·내부링크 자동 삽입
