# 이미지 생성 — 구글 드라이브 경유 (OpenAI Plus 활용, API 비용 0)

사용자 지시(2026-08-19): OpenAI API 대신 ChatGPT Plus로 이미지를 만들고 드라이브로 받는다.

## 흐름
1. 사용자가 "글 써" → Claude: 초안 작성 + 이미지 요청 메일 발송 → 사용자에게 "메일 보냄 + 슬러그" 알림.
2. OpenAI(ChatGPT 예약작업)가 Gmail의 `[JAYLOG-IMG]` 메일을 읽어 이미지 2장 생성 →
   드라이브 폴더 "claude with open ai"(ID: 1YgVR1bgkYyNCvCtNMk3MHROpyZol9xBI) 안에
   `{슬러그}` 하위폴더를 만들고 업로드: `{슬러그}-thumb.png`, `{슬러그}-body.png`.
3. 사용자가 "됐어(처리됨)" 알림 → Claude: 그 하위폴더에서 이미지 2장을 받아
   저장소에 넣고(git), 파이프라인이 그 파일을 워드프레스에 올려 글 완성.

## 메일 규약
- 제목: `[JAYLOG-IMG] {슬러그}`  (수신=사용자 본인 Gmail, 자기에게 보내기)
- 본문 형식:
  ```
  슬러그: {영문 슬러그}
  [썸네일 프롬프트]: ...
  [본문이미지 프롬프트]: ...
  ```

## Claude 쪽 역할
- 메일 발송: Gmail 커넥터. 드라이브 수신: Google Drive 커넥터(Claude 세션에 연동됨).
- 드라이브 이미지 → 저장소 커밋 → 파이프라인이 워드프레스 업로드(파이프라인엔 구글 권한 불필요).
- 아직 이미지가 안 올라왔으면 텍스트로 먼저 등록('썸네일필요') 후 나중에 채우는 것도 가능(add-images 방식).
