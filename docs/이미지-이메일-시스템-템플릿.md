# 이미지 생성 시스템 — 이메일→OpenAI→드라이브 (다른 프로젝트 이식용 템플릿)

Claude가 이미지 요청을 **Gmail로 발송** → **ChatGPT(OpenAI Plus)** 가 그 메일을 읽어 이미지 2장 생성 →
**Google Drive** 지정 폴더에 업로드 → Claude가 받아서 저장소에 커밋 → 발행.
**OpenAI 이미지 API를 안 써서 비용 0** (ChatGPT Plus 구독으로 처리).

아래 3개 블록을 각각 복붙하면 새 프로젝트에서 바로 작동한다. **⚙️ 설정값만 프로젝트에 맞게 바꾼다.**

---

## ⚙️ 설정값 (여기만 바꾸면 됨)

```
PROJECT      = MYBLOG                         # 프로젝트 약칭 (메일 제목 접두어에 사용)
MAIL_PREFIX  = [MYBLOG-IMG]                   # 이미지 요청 메일 제목 접두어 (프로젝트별로 다르게 하면 인박스에서 구분됨)
MY_GMAIL     = your-email@gmail.com           # 본인 Gmail (자기에게 보냄)
DRIVE_FOLDER = "claude with open ai"          # ★기존 폴더 그대로 공유 (새로 안 만들어도 됨)
DRIVE_FOLDER_ID = 1YgVR1bgkYyNCvCtNMk3MHROpyZol9xBI   # ★제이로그와 같은 폴더 공유
```

> **★ 폴더는 프로젝트끼리 공유해도 된다** (사용자 지시 2026-08-21). 이미지는 **글마다 고유한 영문 슬러그**의
> 하위폴더로 들어가므로, 여러 프로젝트가 한 폴더를 써도 서로 안 겹친다. 새 폴더·새 ID 만들 필요 없음.
> (혹시 두 프로젝트에서 같은 슬러그를 쓸 위험이 있으면, 슬러그 앞에 프로젝트 약칭을 붙인다: `myblog-<슬러그>`.)

**사전 준비 (1회):**
1. Claude 세션에 **Gmail 커넥터**(메일 발송)와 **Google Drive 커넥터**(파일 검색·다운로드) 연동.
2. 드라이브 폴더는 **기존 "claude with open ai" 폴더를 공유** — 위 ID 그대로 사용(새로 안 만듦).
3. ChatGPT(OpenAI Plus) 예약작업은 **하나로 두 프로젝트를 다 처리** 가능:
   아래 [블록 B]에서 제목 조건을 `"-IMG]" 를 포함`으로 두면 `[JAYLOG-IMG]`·`[MYBLOG-IMG]` 둘 다 잡는다.
   (프로젝트별로 따로 관리하고 싶으면 접두어별로 예약작업을 나눠도 됨.)

> **★ OpenAI한테 새로 안 알려줘도 되는 조건**: 예약작업은 어느 블로그인지 몰라도 된다(슬러그+프롬프트만 봄).
> - **새 프로젝트도 제목을 기존과 똑같이 쓰면** → OpenAI 손 하나 안 대도 그대로 작동.
> - **새 제목 접두어를 쓰려면** → 예약작업 제목 조건을 딱 한 번 `"-IMG]" 포함`으로 넓혀두면, 그 뒤론 새 프로젝트가 몇 개든 안 알려줘도 자동으로 잡힌다.

## [블록 A] Claude 지시문 — 새 프로젝트의 CLAUDE.md / 규칙에 복붙

```markdown
## 이미지 생성 — 이메일→OpenAI→드라이브 (API 비용 0)
이미지는 OpenAI API로 만들지 않는다. 아래 흐름으로 ChatGPT Plus가 만든 걸 받아 쓴다.

흐름:
1. "글 써" 요청 → 초안 작성 시, 각 글에 **영문 슬러그** + **썸네일 프롬프트** + **본문이미지 프롬프트**를 정한다.
2. 초안은 파이프라인이 조기 등록하지 않게 대기 위치(예: drafts/_pending/)에 두고,
   아래 형식으로 이미지 요청 메일을 **본인 Gmail로 발송**한다(자기에게 보내기). 발송 후 사용자에게
   **"보냈어"(완료형)**로 알린다 — 슬러그도 함께. (미래형 "보낼게" 금지)

   제목: [MYBLOG-IMG] {슬러그}
   본문:
     슬러그: {영문 슬러그}
     [썸네일 프롬프트]: (팔레트·장면·한글 문구까지 구체적으로. 브랜드 로고 금지)
     [본문이미지 프롬프트]: (썸네일과 같은 톤. 텍스트 금지, 숫자만 허용)
     ※ 업로드: 드라이브 "claude images" 폴더에 하위폴더 "{슬러그}" 만들고
       {슬러그}-thumb.png / {슬러그}-body.png 로 올릴 것

3. 사용자가 "됐어/업로드 완료" 하면:
   a. Google Drive에서 `title contains '{슬러그}' and mimeType contains 'image/'` 로 두 파일을 찾는다.
   b. download_file_content로 받는다(용량 커서 결과가 파일로 저장되면, 그 JSON의 content(base64)를
      python으로 디코드해 PNG로 저장 — 컨텍스트에 base64를 올리지 말 것).
   c. drafts/img/{슬러그}-thumb.png, {슬러그}-body.png 로 저장(git add -f, .gitignore가 이미지 막으면 예외 추가).
   d. 대기 위치의 초안을 처리 폴더(drafts/)로 옮기고 커밋·푸시 → 파이프라인이 로컬 이미지로 발행(API 미호출).

주의: 사용자 허락 없이 OpenAI 이미지 API를 절대 호출하지 않는다.
```

## [블록 B] OpenAI(ChatGPT Plus) 예약작업 지시문 — ChatGPT에 복붙

```
[예약작업] 매시간(또는 원하는 주기) 내 Gmail에서 제목에 "-IMG]"가 포함된 안 읽은 메일을 확인한다.
(이렇게 하면 [JAYLOG-IMG]·[MYBLOG-IMG] 등 여러 블로그 프로젝트의 요청을 이 예약작업 하나로 다 처리한다.)
각 메일에 대해:
1. 본문에서 '슬러그', '[썸네일 프롬프트]', '[본문이미지 프롬프트]'를 읽는다.
2. 프롬프트대로 이미지 2장을 생성한다. 가로형(1536x1024 비율), 광고 품질, 브랜드 로고 금지.
   - 썸네일: 프롬프트에 적힌 한글 문구를 정확히 렌더.
   - 본문이미지: 텍스트 없이(숫자만 허용).
3. 내 Google Drive의 "claude with open ai" 폴더(모든 프로젝트 공유) 안에 하위폴더 "{슬러그}"를 만들고
   두 파일을 올린다: {슬러그}-thumb.png , {슬러그}-body.png
   (슬러그가 고유하므로 프로젝트가 달라도 하위폴더가 안 겹친다.)
4. 처리한 메일은 읽음 처리한다.
```

## [블록 C] 실행 순서 요약 (사용자용)

```
1. Claude에게 "글 써" → Claude가 초안 + 이미지 요청 메일 발송 → "보냈어 (슬러그: xxx)" 알림.
2. 나(사용자)는 아무것도 안 해도 됨 — ChatGPT 예약작업이 알아서 메일 읽고 드라이브에 이미지 올림.
   (또는 ChatGPT에게 "지금 확인해" 한마디로 즉시 실행)
3. 드라이브에 이미지 2장 올라온 걸 확인하면 Claude에게 "업로드 완료" → Claude가 받아서 발행.
```

## 트러블슈팅
- **다운로드 결과가 너무 커서 컨텍스트 초과**: 정상. 결과가 파일로 저장되니 그 파일의 `content`(base64)를 python `base64.b64decode`로 PNG 저장.
- **.gitignore가 `*-thumb.png`/`post*.png` 등으로 이미지를 막음**: `drafts/img/` 예외(`!drafts/img/`, `!drafts/img/*`) 추가 후 `git add -f`.
- **이미지가 아직 안 올라옴**: 텍스트로 먼저 등록 후 나중에 이미지만 교체(swap-thumb 방식)도 가능. 급하지 않으면 이미지 올라온 뒤 발행 권장.
