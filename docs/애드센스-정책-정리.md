# 애드센스 정책 정리 — 제이로그 기준 (2026-08-20)

2026-08-20 재신청 준비 중, 구글이 참고로 준 정책·가이드 원문 스크린샷을 전부 정리한 문서.
**핵심: 우리 실제 거절 사유는 딱 하나 — "가치가 별로 없는 콘텐츠(Low value content)."** 나머지 정책들은 위반한 게 아니라 일반 기준(참고용)이다. 각 항목에 우리 블로그 관련도·상태를 표시.

---

## 0. 실제 거절 화면 (결정적)

> **정책 위반이 발견되었습니다 → 가치가 별로 없는 콘텐츠**
> "사이트가 Google 게시자 네트워크의 사용 기준을 충족하지 않습니다."
> 참고 자료 4개: ① 최소 콘텐츠 요건 ② 고유 콘텐츠·우수한 UX ③ 내용이 빈약한 콘텐츠 가이드 ④ 웹마스터 품질 가이드라인

- 사이트 소유권 확인은 ✅ 통과.
- **위반 항목은 이 1개뿐.** 아래 불법·성적·저작권 등은 우리가 걸린 게 아님(일반 정책 원문).

## 1. 콘텐츠 정책 (Google Publisher Policies) — 금지 콘텐츠

| 항목 | 내용 요약 | 우리 관련도 |
|---|---|---|
| **Illegal content** | 불법이거나 불법 조장·타인 권리 침해 | ⚠️ **의약품·처방약·니코틴 액상 직구 = 불법 → 주제 금지**(규칙 반영) |
| **Intellectual property abuse** | 저작권 침해(DMCA), **짝퉁·위조품** 판매·홍보 | ⚠️ 짝퉁·정품인증 우회 글 금지 |
| **Dangerous/derogatory** | 증오·차별, 괴롭힘, 자·타해 조장, 테러·마약조직, 강요·갈취 | 무관 |
| **Animal cruelty** | 동물학대, 멸종위기종(상아·코뿔소뿔 등) 판매 | 무관 |
| **Misleading representation** | 게시자·콘텐츠 목적을 속임, 가짜 제휴·보증 | 🔶 저자·운영주체 정직하게(신뢰 페이지로 충족) |
| **Unreliable/harmful claims** | 선거·의학(백신부정·가짜치료)·기후 등 검증된 합의에 반하는 허위 | 무관(직구 정보) |
| **Deceptive practices** | 거짓 유인, 피싱, "Get Rich Quick", 정체 은폐 | 🔶 과장·낚시 금지 |
| **Manipulated media** | 정치·사회 이슈 조작 미디어 | 무관 |
| **Enabling dishonest behavior** | 위조문서, 해킹/크래킹·DRM 우회, 스파이웨어 | ⚠️ 우회·해킹 안내 금지 |
| **Sexually explicit / 성 관련** | 노골적 성적 콘텐츠, 성매매, 국제결혼중개, 가족용 위장 성인물 | 무관 |

→ **우리에게 실질적으로 중요한 것: 불법(의약품·니코틴·짝퉁·우회) 주제 금지.** 이미 규칙(CLAUDE.md)에 반영·post 59 삭제.

## 2. Inventory value (광고 지면 가치) — ★우리가 걸린 계열

| 항목 | 내용 | 우리 상태 |
|---|---|---|
| **Low-value content** | 게시자 콘텐츠가 없거나 **저가치**인 화면에 광고 금지 | 🔴 **거절 사유 본체** → 27개 개선으로 대응 |
| **Replicated content** | 남의 콘텐츠 복붙, 부가가치 없이 재게시 | 🔴 자기복제·중복 제거 완료 |
| **Out of context ads** | 배경·화면 밖 광고 등 | 무관(정상 배치) |
| **More ads than content** | 콘텐츠보다 광고·홍보물이 많음 | 🔶 광고 승인 후 배치 시 주의 |
| **Unsupported languages** | 지원 언어(한국어 포함)로 작성 | ✅ 한국어 |

→ **재신청의 핵심 전장.** 독창성·중복 제거·깊이가 전부 여기로 수렴.

## 3. Privacy 정책 (개인정보)

| 항목 | 내용 | 우리 상태 |
|---|---|---|
| **Personalized advertising** | 13세 미만·민감정보(건강·재정·인종·종교·정치·성적취향 등) 기반 맞춤광고 금지 | 무관(정보 수집 안 함) |
| **Privacy disclosures** | **쿠키·제3자·IP 수집을 개인정보처리방침에 고지 필수** | ✅ 개인정보처리방침에 애드센스·쿠키·제3자 조항 있음 |
| **Cookies on Google domains** | 구글 도메인 쿠키 조작 금지 | 무관 |
| **Identifying users** | 개인식별정보를 구글에 넘기지 않기, EU 동의 정책 준수 | ✅ 해당 없음 |

→ **이미 충족.** 개인정보처리방침 페이지가 요건을 커버.

## 4. AdSense "콘텐츠 및 사용자 경험" 가이드 — ★품질 기준표

거절 사유가 링크한 핵심 문서. 우리가 맞춰야 할 실제 잣대.

1. **충분히 독창적인 콘텐츠**: 비슷한 주제 사이트 대비 실질적 가치·독창성, 재방문 이유. 정기 업데이트.
   → 대응: 가짜 일화 제거, 자기복제 압축, 국가·주제별 차별화. (다음 단계: 실제 화면 캡처·자체 비교표)
2. **중복 콘텐츠 금지**: 복사·약간 수정 재게시·미디어 삽입만 하는 페이지 금지. **"모든 페이지 하단 긴 고지문 반복 말고, 짧은 요약+상세 링크로."** 유사 페이지는 확장하거나 **통합**.
   → 대응: 고지문 경량화·변주, 중복 4글 통합·삭제(31→27).
3. **탐색(내비게이션)·UX**: 메뉴/카테고리 정리, 다양한 브라우저 정상 표시, 깨진 링크·누락 페이지·주제 무관 페이지 없기.
   → 대응: 내부링크 보강(19·28·277 등으로 연결).
4. **사이트 검토 제출**: 정리 후 '문제 수정 확인' 체크 → 검토 요청.

## 5. Search Console 수동조치 (Manual actions) — Thin content

거절과 같은 계열 개념. **아직 실제 수동조치가 뜬 건 아님**(참고 도움말). 정의:

- **Thin content with little or no added value** = 저품질·얕은 페이지. 대표 예:
  - **Thin affiliate pages** (알맹이 없는 제휴/정보 페이지)
  - **Scraped content** (긁어온 내용)
  - **Doorways** (검색 유입용 관문 페이지)
- 해결: 중복 확인 → **사용자에게 실질적 부가가치** 제공하게 개선 → Request Review.

→ 우리 27개 개선이 정확히 이 3가지(thin·scraped·doorway) 인상을 없애는 작업이었음.

## 6. Spam 정책 (Google 웹검색)

- 웹검색 스팸 정책 위반 화면에 광고 금지. 관련: **클로킹·도어웨이·콘텐츠 거의 없는 페이지·특정 키워드 과최적화 금지.**
- **Scaled content abuse**(대량 양산 콘텐츠): 검색 조작 목적의 대량 페이지 = 제작 방식(AI 여부) 무관하게 감점.
  → 대응: 하루 1개는 유지하되 **양보다 질**, 획일 틀·양산 인상 제거.

| 요건 | 상태 |
|---|---|
| 불법(의약품·니코틴·짝퉁·우회) 주제 배제 | ✅ 규칙화 + post 59 삭제 |
| 개인정보처리방침(쿠키·제3자·애드센스 고지) | ✅ 있음 |

| 획일 틀·반복 보일러플레이트 완화 | ✅ 고지문 변주·CTA 18종·가짜 일화 삭제 |
| 독창적 부가가치(여기에만 있는 것) | 🔶 진행중 — 다음: 실제 화면 캡처·자체 비교표 |
| 정기 업데이트 | 🔶 재검토 중 질 위주로 유지 |

**결론**: 걸린 건 '저가치 콘텐츠' 하나. 나머지 정책은 이미 충족했거나 무관. 재승인 열쇠는 **독창성·중복제거·깊이** — 그 방향으로 개선 완료했고, 부족하면 '실제 화면 캡처·자체 데이터' 글로 보강한다.
